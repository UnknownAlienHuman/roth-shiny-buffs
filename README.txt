RothShinyBuffs (Midnight 12.0)

- Reskins Blizzard Buff/Debuff icons (aura buttons) with Galaxy-style frames.
- Does NOT move/resize aura containers; use Blizzard Edit Mode for positioning.
- Uses embedded LibSharedMedia-3.0 for border/background selection.
- Optional Masque integration (Masque must be installed/enabled).

Settings: ESC -> Options -> AddOns -> RothShinyBuffs
